## 3.1 Reaksi Kimia

```prompt Template 3.1 · Reaksi Pembakaran
Logam natrium dimasukkan ke dalam air, bereaksi hebat menghasilkan hidrogen dan panas, gelembung gas terlihat, nyala api kuning-orange, gaya demonstrasi laboratorium aman, 16:9.
```

```prompt Template 3.2 · Reaksi Asam-Basa
Larutan asam ditambahkan ke larutan basa dengan indikator酚olftalein, perubahan warna dari tak berwarna ke merah muda menunjukkan netralisasi, grafik pH muncul di samping, gaya animasi kimia edukatif, 16:9.
```

```prompt Template 3.3 · Reaksi Presipitasi
Dua larutan jernih dicampur, endapan putih segera terbentuk, partikel endapan mengendap ke dasar, gaya visualisasi reaksi kimia makroskopis, 16:9.
```

```prompt Template 3.4 · Reaksi Redoks
Zat zinc dicelupkan ke dalam larutan tembaga sulfat, zinc melarut sementara tembaga mengendap, perubahan warna larutan dari biru menjadi tak berwarna, gaya animasi elektrokimia, 16:9.
```

## 3.2 Struktur Atom dan Ikatan

```prompt Template 3.5 · Model Atom Bohr
Atom hidrogen dengan elektron berorbit di kulit tertentu, transisi elektron antar tingkat energi memancarkan foton cahaya, spektrum emisi terlihat, gaya ilustrasi sains klasik, 16:9.
```

```prompt Template 3.6 · Ikatan Ion
Atom natrium melepaskan elektron kepada atom klorin, terbentuk ion Na+ dan Cl- yang saling tarik-menarik, kisi kristal NaCl terbentuk, gaya animasi molekuler 3D, 16:9.
```

```prompt Template 3.7 · Ikatan Kovalen
Dua atom hidrogen berbagi pasangan elektron, orbital_overlap terlihat, molekul H2 terbentuk stabil, gaya visualisasi mekanika kuantum sederhana, 16:9.
```

## 3.3 Larutan dan Konsentrasi

```prompt Template 3.8 · Proses Pelarutan
Kristal gula dilarutkan dalam air, molekul gula terpisah dan tersebar merata di antara molekul air, animasi tingkat molekuler, gaya visualisasi kimia larutan, 16:9.
```

```prompt Template 3.9 · Elektrolit vs Non-elektrolit
Larutan NaCl menghantarkan listrik (bola lampu menyala), larutan gula tidak, perbandingan visual dua bejana, gaya demonstrasi sifat koligatif, 16:9.
```

```prompt Template 3.10 · Kelarutan dan Suhu
Garam dapur dilarutkan dalam air dingin dan air panas, kelarutan lebih tinggi pada suhu panas, kristal lebih cepat larut, gaya eksperimen laboratorium, 16:9.
```

## 3.4 Kimia Organik

```prompt Template 3.11 · Struktur Metana (CH4)
Molekul metana dengan geometri tetrahedral, empat ikatan C-H sama panjang, sudut ikatan 109.5 derajat, rotasi molekul perlahan, gaya visualisasi 3D molekuler, 16:9.
```

```prompt Template 3.12 · Isomeri
Dua molekul dengan rumus molekul sama (C4H10) tetapi struktur berbeda (n-butana dan isobutana), perbandingan struktur garis dan ruang, gaya ilustrasi kimia organik, 16:9.
```

:::summary Intisari
Prompt kimia efektif ketika menampilkan perubahan tingkat makro (warna, endapan) bersamaan dengan penjelasan tingkat mikro (molekul, ion).
:::
