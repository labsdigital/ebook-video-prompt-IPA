## 3.1 Reaksi Kimia

```prompt Template 3.1 · Reaksi Pembakaran Natrium
Logam natrium dimasukkan ke dalam air, bereaksi hebat menghasilkan hidrogen dan panas, gelembung gas terlihat menyebar, nyala api kuning-orange karakter natrium muncul — visualisasi reaksi logam alkali dengan air, panel menunjukkan persamaan reaksi 2Na + 2H2O → 2NaOH + H2, gaya demonstrasi laboratorium aman dengan防护 shield, rasio 16:9.
```

```prompt Template 3.2 · Reaksi Asam-Basa (Netralisasi)
Larutan asam ditambahkan ke larutan basa dengan indikator酚olftalein, perubahan warna dari tak berwarna ke merah muda menunjukkan titik netral — visualisasi titrasi dengan buret dan erlenmeyer, grafik pH curve muncul di panel samping, perubahan pH real-time ditampilkan, gaya animasi kimia edukatif laboratorium, rasio 16:9.
```

```prompt Template 3.3 · Reaksi Presipitasi
Dua larutan jernih (AgNO3 dan NaCl) dicampur, endapan putih AgCl segera terbentuk — visualisasi reaksi pengendapan dengan partikel endapan mengendap ke dasar beaker, panel menunjukkan persamaan ion lengkap, gaya visualisasi reaksi kimia makroskopis dengan transisi ke level molekuler, rasio 16:9.
```

```prompt Template 3.4 · Reaksi Redoks (Zn dan CuSO4)
Zat zinc dicelupkan ke dalam larutan tembaga sulfat biru, zinc melarut sementara tembaga mengendap berwarna coklat kemerahan, perubahan warna larutan dari biru menjadi tak berwarna — visualisasi reaksi redoks dengan transfer elektron, panel potensial reduksi standar ditampilkan, gaya animasi elektrokimia dengan arrow elektron, rasio 16:9.
```

```prompt Template 3.5 · Laju Reaksi (Faktor-faktor)
Empat tabung reaksi dengan kondisi berbeda (suhu, konsentrasi, luas permukaan, katalis) direaksikan simultan — visualisasi pengaruh faktor terhadap laju reaksi dengan waktu reaksi ditampilkan, panel grafik konsentrasi-waktu untuk tiap kondisi, gaya demonstrasi kinetika kimia, rasio 16:9.
```

## 3.2 Struktur Atom dan Ikatan

```prompt Template 3.6 · Model Atom Bohr
Atom hidrogen dengan elektron berorbit di kulit tertentu (n=1, n=2, n=3), transisi elektron antar tingkat energi memancarkan foton cahaya dengan energi spesifik — visualisasi spektrum emisi hidrogen dengan garis-garis warna berbeda, panel energi tingkat elektron, gaya ilustrasi sains klasik dengan animasi transisi, rasio 16:9.
```

```prompt Template 3.7 · Ikatan Ion (NaCl)
Atom natrium melepaskan elektron kepada atom klorin, terbentuk ion Na+ dan Cl- yang saling tarik-menarik dengan gaya elektrostatis, kisi kristal NaCl tiga dimensi terbentuk — visualisasi pembentukan ikatan ion dengan transfer elektron Animasi, panel konfigurasi elektron sebelum dan sesudah, gaya animasi molekuler 3D, rasio 16:9.
```

```prompt Template 3.8 · Ikatan Kovalen (H2)
Dua atom hidrogen berbagi pasangan elektron, orbital_overlap terlihat sebagai awan elektron, molekul H2 terbentuk stabil dengan ikatan sigma — visualisasi mekanika kuantum sederhana dengan representasi orbital s, panel energi ikatan dan panjang ikatan, gaya visualisasi kimia kuantum edukatif, rasio 16:9.
```

```prompt Template 3.9 · Ikatan Logam
Atom-atom logam tersusun dalam kisi dengan elektron valensi bergerak bebas di seluruh struktur — visualisasi "lautan elektron" dengan elektron-elektron bergerak dinamis, panel menjelaskan sifat konduktivitas listrik dan panas, gaya animasi struktur kristal logam, rasio 16:9.
```

```prompt Template 3.10 · Ikatan Hidrogen (Air)
Molekul-molekul air berinteraksi melalui ikatan hidrogen antara hidrogen satu molekul dengan oksigen molekul lain — visualisasi struktur jaringan ikatan hidrogen, panel menunjukkan sudut dan jarak ikatan, transisi ke sifat unik air (titik didih tinggi, density anomaly), gaya visualisasi kimia larutan, rasio 16:9.
```

## 3.3 Larutan dan Konsentrasi

```prompt Template 3.11 · Proses Pelarutan Gula
Kristal gula (sukrosa) dilarutkan dalam air, molekul gula terpisah dan tersebar merata di antara molekul air — animasi tingkat molekuler menunjukkan proses solvasi dengan air mengelilingi molekul gula, panel konsentrasi real-time, gaya visualisasi kimia larutan dengan transisi makro-mikro, rasio 16:9.
```

```prompt Template 3.12 · Elektrolit vs Non-elektrolit
Larutan NaCl menghantarkan listrik (bola lampu menyala terang), larutan gula tidak menghantarkan (lampu redup/tidak nyala) — perbandingan visual dua bejana dengan rangkaian listrik, panel menunjukkan ion vs molekul netral, gaya demonstrasi sifat koligatif elektrolit, rasio 16:9.
```

```prompt Template 3.13 · Kelarutan dan Suhu
Garam dapur (NaCl) dan gula (sukrosa) dilarutkan dalam air dingin dan air panas, kelarutan berbeda pada suhu berbeda — visualisasi grafik kelarutan vs suhu untuk berbagai zat, panel data tabel kelarutan, gaya eksperimen laboratorium terkontrol, rasio 16:9.
```

```prompt Template 3.14 · Pengenceran Larutan
Larutan pekat diencerkan dengan penambahan pelarut, konsentrasi menurun namun jumlah mol zat terlarut tetap — visualisasi proses pengenceran dengan panel perhitungan M1V1 = M2V2, animasi partikel zat terlarut semakin jarang, gaya demonstrasi laboratorium analitik, rasio 16:9.
```

## 3.4 Kimia Organik

```prompt Template 3.15 · Struktur Metana (CH4)
Molekul metana dengan geometri tetrahedral, empat ikatan C-H sama panjang, sudut ikatan 109.5 derajat — rotasi molekul perlahan menunjukkan simetri tetrahedral, panel hibridisasi sp3 dan konfigurasi elektron, gaya visualisasi 3D molekuler dengan ball-and-stick model, rasio 16:9.
```

```prompt Template 3.16 · Isomeri Struktural
Dua molekul dengan rumus molekul sama (C4H10) tetapi struktur berbeda (n-butana lurus vs isobutana bercabang) — perbandingan struktur garis (structural formula) dan model ruang, panel titik didih dan sifat fisik berbeda, gaya ilustrasi kimia organik edukatif, rasio 16:9.
```

```prompt Template 3.17 · Reaksi substitusi Metana
Metana bereaksi dengan klorin sotto UV light, hidrogen diganti klorin membentuk CH3Cl, CH2Cl2, dll — visualisasi mekanisme reaksi radikal bebas dengan tahap inisiasi, propagasi, terminasi, panel persamaan reaksi berantai, gaya animasi kimia organik mekanisme, rasio 16:9.
```

```prompt Template 3.18 · Polimerisasi
Molekul-molekul etilena (C2H4) berikatan membentuk polietilena panjang — visualisasi reaksi polimerisasi adisi dengan rantai karbon bertambah, panel menunjukkan satuan berulang -(CH2-CH2)n-, gaya animasi kimia polimer, rasio 16:9.
```

:::summary Intisari
Prompt kimia efektif ketika menampilkan perubahan tingkat makro (warna, endapan, gelembung) bersamaan dengan penjelasan tingkat mikro (molekul, ion, elektron). Gunakan transisi visual dari makro ke mikro untuk pemahaman konseptual.
:::
