## 1.1 Elemen Prompt Video Sains

Prompt video AI yang baik untuk konten sains harus mencakup lima elemen kunci:

```prompt Template 1.1 · Struktur Dasar Prompt Video Sains
### SUBJEK
Objek utama dalam video (misal: molekul air, planet, sel, reaksi kimia)

### AKSI / PERUBAHAN
Apa yang terjadi? ( Jatuh, bereaksi, berputar, tumbuh, mengalir )

### KONTEKS VISUAL
Latar belakang dan lingkungan ( Laboratorium, ruang kelas, luar angkasa, mikroskopis )

### GAYA VISUAL
Realistik, ilustrasi 2D, 3D render, animasi eksploratori, dll.

### PARAMETER TEKNIS
Rasio aspek, durasi, kualitas, sudut kamera
```

## 1.2 Contoh Prompt Lengkap

Berikut adalah contoh prompt yang menggabungkan semua elemen:

```prompt Template 1.2 · Contoh Prompt Lengkap
Sebuah molekul air (H2O) berputar perlahan di tengah layar,
dengan ikatan hidrogen terlihat sebagai garis-garis connector,
latar belakang gelap dengan partikel air mengambang,
gaya visualisasi ilmiah 3D, pencahayaan dramatis,
sudut pandang isometrik, rasio 16:9, kualitas tinggi.
```

## 1.3 Formula Prompt Efektif

Gunakan formula ini untuk membuat prompt yang konsisten:

```prompt Template 1.3 · Formula Prompt Sains
[Objek/substrat] + [Aksi/perubahan yang terjadi] + [Detail visual tambahan] + [Lingkungan/konteks] + [Gaya visual/gambar] + [Parameter teknis]
```

**Contoh penerapan:**
- Subjek: "Molekul air"
- Aksi: "berinteraksi membentuk ikatan hidrogen"
- Detail: "setiap ikatan digarisbawahi dengan warna berbeda"
- Lingkungan: "latar hitam dengan grid koordinat halus"
- Gaya: "3D scientific visualization, soft studio lighting"
- Parameter: "16:9, slow rotation, high detail"

**Hasil final:**
"Molekul air H2O berinteraksi membentuk ikatan hidrogen dengan pasangan molekul lain, setiap ikatan digarisbawahi dengan warna biru neon, latar hitam dengan grid koordinat halus, gaya 3D scientific visualization dengan soft studio lighting, rasio 16:9, rotasi lambat, detail tinggi."

## 1.4 Tips Memaksimalkan Prompt

:::tip Tips Penting
- **Spesifik tapi tidak berlebihan** — 2-4 klausa sudah cukup
- **Gunakan kata kerja aktif** — "berputar", "mengalir", "bereaksi"
- **Sebutkan skala** — "molekuler", "mikroskopis", "planet"
- **Tentukan sudut kamera** — "close-up", "wide shot", "bird's eye"
- **Tambahkan pencahayaan** — "studio lighting", "natural light", "dramatic"
- **Jelaskan gerakan kamera** — "zoom in", "pan", "rotate", "static"
:::

:::tip Variasi Sudut Kamera
- **Close-up**: Fokus pada detail kecil (sel, molekul)
- **Medium shot**: Menunjukkan interaksi antar objek
- **Wide shot**: Konteks lengkap (sistem, ekosistem)
- **Bird's eye**: Pandangan dari atas (baik untuk peta, diagram)
- **Eye-level**: Sama seperti mata pengamat (realistis)
:::

:::warning Hindari
Jangan gunakan prompt yang terlalu panjang (>50 kata). AI video generator bekerja terbaik dengan instruksi yang fokus dan jelas. Terlalu banyak detail bisa menyebabkan output yang bingung.
:::

## 1.5 Parameter Teknis yang Umum

| Parameter | Opsi Umum | Keterangan |
|---|---|---|
| Rasio Aspek | 16:9, 9:16, 1:1, 4:3 | Sesuaikan dengan platform tujuan |
| Durasi | 3s, 5s, 10s | Semakin pendek, semakin stabil |
| Kualitas | High, 4K, HD | Mempengaruhi detail output |
| Sudut Kamera | Close-up, Wide, Bird's eye | Mempengaruhi perspektif |
| Gerakan Kamera | Zoom in, Pan, Rotate | Menambah dinamis |
| Kecepatan | Slow motion, Normal, Timelapse | Untuk efek dramatis |
| Pencahayaan | Studio, Natural, Dramatic | Memengaruhi mood |

:::summary Intisari
Prompt video sains yang efektif = Subjek + Aksi + Konteks + Gaya + Parameter. Semakin spesifik elemen-elemen ini, semakin baik hasil videonya.
:::
