:::goals
- Mendapatkan prompt video untuk konsep-konsep fisika dasar
- Memvisualisasikan gerak, gaya, dan energi
- Membuat animasi gelombang dan optik
:::

## 2.1 Mekanika: Gerak dan Gaya

```prompt Template 2.1 · Hukum Newton I (Inersia)
Sebuah bola besi diam di atas meja datar, kemudian ditabrak bola lain, bergerak lurus — visualisasi hukum inersia Newton, gaya gesek terlihat sebagai jejak, gaya realistis, studio lighting, sudut samping, 16:9.
```

```prompt Template 2.2 · Hukum Newton II (F=ma)
Dua gerobak dengan massa berbeda ditarik dengan gaya sama, gerobak ringan bergerak lebih cepat — visualisasi F=ma, grafik percepatan muncul di samping, gaya colorful arrows, gaya ilustrasi edukatif, 16:9.
```

```prompt Template 2.3 · Hukum Gravitasi
Sebuah benda jatuh bebas dari ketinggian, percepatan gravitasi menunjukkan peningkatan kecepatan, jejak gerakan terlihat, latar ruang kelas, gaya dokumenter sains, 16:9.
```

```prompt Template 2.4 · Gerakan Proyektil
Peluru ditembakkan dari bidang miring, lintasan parabola terlihat jelas dengan grid koordinat, sudut lepas 45 derajat menghasilkan jarak terjauh, gaya animasi pendidikan, 16:9.
```

## 2.2 Energi dan Usaha

```prompt Template 2.5 · Energi Kinetik dan Potensial
Bandul ayunan bergerak bolak-balik, energi potensial maksimum di titik tertinggi, energi kinetik maksimum di titik terendah, diagram energi muncul di samping, gaya visualisasi ilmiah, 16:9.
```

```prompt Template 2.6 · Hukum Kekekalan Energi
Bola roller coaster turun dari ketinggian, kecepatan meningkat di turunan, berkurang di tanjakan, total energi tetap (ditampilkan sebagai grafik), gaya animasi 3D edukatif, 16:9.
```

```prompt Template 2.7 · Energi Panas dan Pemuaian
Batang logam dipanaskan, memuai dan memanjang, skala pengukuran terlihat di samping, perubahan suhu ditampilkan dengan termometer digital, gaya demonstrasi laboratorium, 16:9.
```

## 2.3 Gelombang dan Bunyi

```prompt Template 2.8 · Gelombang longitudinal (Bunyi)
Suatu sumber bunyi bergetar, partikel udara bergetar longitudinal membentuk rapatan dan regangan, visualisasi gelombang berjalan, warna berbeda untuk rapatan (merah) dan regangan (biru), gaya animasi sains, 16:9.
```

```prompt Template 2.9 · Gelombang transversal
Tali digetarkan, gelombang transversal merambat dengan puncak dan lembah, frekuensi dan amplitudo terlihat jelas, grid latar membantu pengukuran, gaya simulasi interaktif, 16:9.
```

```prompt Template 2.10 · Interferensi Gelombang
Dua sumber gelombang bertemu, pola interferensi konstruktif dan destruktif terbentuk, animasi real-time, latar gelap dengan gelombang berwarna, gaya visualisasi fisika modern, 16:9.
```

## 2.4 Optik dan Cahaya

```prompt Template 2.11 · Pemantulan Cahaya
Sinar cahaya mengenai cermin datar, sudut datang sama dengan sudut pantul, garis normal terlihat, hukum pemantulan diverifikasi visual, gaya diagram optik edukatif, 16:9.
```

```prompt Template 2.12 · Pembiasan Cahaya
Sinar cahaya masuk dari udara ke air, membelok akibat perbedaan indeks bias, sudut datang dan sudut bias ditandai, hukum Snellius divisualisasikan, gaya animasi fisika optik, 16:9.
```

```prompt Template 2.13 · Lensa Cembung
Benda diletakkan di depan lensa cembung, bayangan riil terbentuk di layar, hubungan jarak benda-ayang-diverifikasi visual, gaya demonstrasi laboratorium optik, 16:9.
```

:::summary Intisari
Prompt fisika berfokus pada visualisasi hukum dan prinsip — gunakan kata kunci seperti "hukum", "demonstrasi", "grafik", "diagram" untuk hasil yang edukatif.
:::
